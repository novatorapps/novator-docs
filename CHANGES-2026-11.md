# Docs refresh, November 2026: change record

Status: **preview only** (noindex). Production (novatorapps.com, `main`) is unchanged until approved.
- Website: https://preview.novatorapps-site.pages.dev (future novatorapps.com)
- Guides: https://preview.novator-docs.pages.dev (future docs.novatorapps.com)

## 0. New structure (added after second preview)
- **novatorapps.com** becomes the company site: Novator Technologies as an official Odoo partner for apps, integrations and custom development. Pages: Home, Apps (catalog), Services (custom apps, integrations, implementation via novator.co, request email), Articles, Contact. Built from `site.config.js` in the same repo (`npm run build:site`, output `build-site`), Cloudflare Pages project `novatorapps-site`.
- Partner wording follows the odoo.com listing (Ready level, certified experts): "Official Odoo Partner" with a link to the listing. No tier, customer counts, testimonials or ratings. Footer notes that Odoo is a trademark of Odoo S.A.
- **docs.novatorapps.com** hosts the guides (`docusaurus.config.js`, project `novator-docs`). Articles and the custom app request moved to the website.
- Redirects: old novatorapps.com/<guide> URLs to docs.novatorapps.com (`static-site/_redirects`); docs.novator.co and www.novatorapps.com by host (`functions/_middleware.js`).
- Shared: `apps.json`, `src/components/Catalog.js`, styles, logo, feedback counters. Separate `robots.txt` and sitemaps per host.
- Launch steps (after approval): add docs.novatorapps.com to `novator-docs`; move novatorapps.com and www to `novatorapps-site`; Hasan updates the DNS records; publish both from `main`.

## 1. Catalog and discovery
- Home page is now a catalog: search, filters for category, free or paid, and Odoo version, a count, and per app: category, summary, edition and price tags, Odoo versions, links to the guide and to the free and Pro store pages.
- `apps.json` has a `category` per app. `sync_app.py check` writes `store_free`, `store_pro` and `category` to `src/data/apps.json` and fails when a category is missing.

## 2. SEO
- `robots.txt` with the sitemap. `_headers`: `X-Robots-Tag: noindex` on novator-docs.pages.dev, preview URLs and docs.novator.co, so only novatorapps.com is indexed. Long cache for hashed assets.
- SoftwareApplication JSON-LD on each app overview (name, category, Odoo versions, offers with the published price, publisher). No ratings or reviews.
- Existing canonical URLs, sitemap, Open Graph, meta descriptions and breadcrumbs kept.

## 3. Installation, compatibility and release notes (every app)
- New **Installation** page per app, generated by `tools/gen_pages.py` from `apps.json` and `data/modules.json` (manifest facts): supported versions, Community and Enterprise on Odoo.sh or own server (as stated on every store page), modules with technical name, edition, license and required Odoo apps, install, update and problem reporting steps.
- Correct dependency notes: Pro needs the free app for Dashboard Builder, Access Manager and AI Connector; Storage Manager and Device Access Control do not need their free companions.
- New **Release notes** page per app from `data/releases.json`, written from git history and manifest versions with real dates. Versions whose commits only changed the store page are marked as description updates.

## 4. Support
- New **Support** page: what to include, bug reports, improvement requests, updates, purchases through Odoo. No response times or warranties promised.

## 8. Feedback and measurement
- "Was this page helpful?" on every guide page, one vote per page per browser.
- Pages Function `functions/api/event.js` counts helpful votes and clicks on Odoo Apps Store links in KV namespace `novator-docs-events` (binding `EVENTS`, `wrangler.toml`). No IP, cookies or personal data. Preview traffic is stored under `preview:`. `tools/stats.sh` prints the counters.
- Limits: a store click is not a purchase; purchases happen on apps.odoo.com and cannot be measured here. Counters are approximate (KV is not transactional).
- Cloudflare Web Analytics: to be switched on by Hasan in the Pages project (Metrics > Web Analytics). Cookie-free page views; it has no custom events, hence the function above.

## 8b. Requests (added after first preview)
- **Request this version** on every Installation page, for Odoo versions 13.0 to 20.0 the app does not support yet. Opens an email to support@novator.co with subject "Version request: <app> for Odoo <version>" and counts `version:<slug>:<version>`.
- Custom app request (now on the website, /services#request; first built as a docs page /custom-app, which redirects): what to send, one email button (subject "App request: "), counted as `app_request`. Linked from the catalog, the footer and Support. No prices, timelines or promises.
- Email, not a form: no personal data stored and no spam handling needed.
