# FAQ and troubleshooting

### Does it match Odoo's stock?

Yes. It uses done stock moves in each product's unit of measure, so partial deliveries count what was really shipped, and the closing equals Odoo's quantity on hand at that date.

### Is it fast on large databases?

Yes. All movements are read in one database query per location, not product by product.

### Does it show stock value?

This version reports quantities. Contact us if you need values.

### Several companies?

Supported, one company per report.

## Still stuck?

Write to **support@novator.co** with your Odoo version, the app version (Apps, open the app) and a screenshot.
