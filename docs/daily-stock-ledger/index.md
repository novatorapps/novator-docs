# Daily Stock Report and Stock Ledger

"How much did we have on the 1st, and where did it go?" Pick a period and one or more warehouses: see each product's **opening stock**, every kind of **movement** and its **closing stock**. Then follow any product move by move in the **Stock Ledger**, with a running balance.

<span className="version-pill">Odoo 17.0 - 20.0</span> <span className="version-pill">Community &amp; Enterprise</span> <span className="version-pill">$149, one-time</span>

![Daily Stock Report](/img/daily-stock-ledger/daily_stock_report.png)

- **Stock at any date**, in your timezone, for one warehouse or several.
- **Every movement by type**: vendors, customers, returns, adjustments, scrap, transfers and manufacturing, each in its own column.
- **Figures that reconcile**: done quantities in the product unit, sub-locations included; the closing equals Odoo's own stock at that date.
- **PDF and Excel** for both reports.

No configuration needed. Every Inventory user can use it; results are private to the user who generated them.
