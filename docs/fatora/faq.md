# FAQ and troubleshooting

### Which Odoo versions?

Odoo 18.0. Contact us for other versions.

### Test Connection fails

Check the API key in your Fatora dashboard (test and live keys are different) and that your server can reach the internet.

### A test payment was refused

Test payments are refused once the provider is **Enabled**. Use **Test Mode** for trials.

### Can I refund part of a payment?

No. Fatora offers full refunds only.

## Still stuck?

Write to **support@novator.co** with your Odoo version, the transaction reference and a screenshot.
