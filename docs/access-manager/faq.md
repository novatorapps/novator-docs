# FAQ and troubleshooting

### Can I lock myself out?

No. Settings administrators are never restricted by profiles.

### Is it only hidden in the screens?

No. Read-only users, import, export and Pro's document type, field, record, button and chatter rules are enforced by the server too, also through the API and AI connectors. Hidden tabs, menus, filters and followers are hidden in the screens.

### A user still sees a hidden menu

Users see changes at their next page load: ask them to refresh. Check that the profile is active and, if it is limited to companies, that the user is working in one of them.

### What happens when I upgrade Odoo?

With Pro, export your profiles before and import them after. Nothing to uninstall.

## Still stuck?

Write to **support@novator.co** with your Odoo version, the app version (Apps, open the app) and a screenshot. With Pro, include a screenshot of **Explain Access** for the user.
