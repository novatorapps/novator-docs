# Access Manager

Control what each user sees and does in Odoo, **without writing code**. Group restrictions in **access profiles** such as *Sales team*, *Warehouse staff* or *External auditors*, and pick the users. Administrators are never restricted, so nobody locks themselves out.

<span className="version-pill">Odoo 17.0 - 20.0</span> <span className="version-pill">Community &amp; Enterprise</span>

![An access profile for warehouse staff](/img/access-manager/profile_form.png)
