# Support

Write to **[support@novator.co](mailto:support@novator.co)** for help with any Novator app, free or paid.

## Before you write

Many questions are answered in the guide of the app. Each guide has an **Installation** page, a **FAQ** with common problems, and **Release notes** that list what changed in each version. You can search all guides with the search box at the top of this site.

## What to include

A complete first message saves a round trip. Please send:

1. **The app** and its version. Turn on developer mode, open **Apps**, remove the **Apps** filter, search for the app and open its **Module Info**. The version is listed there.
2. **Your Odoo version and edition**, for example Odoo 18.0 Enterprise, and where it runs: Odoo.sh or your own server.
3. **What you did**, step by step, and what you expected to happen.
4. **What happened instead**: a screenshot, and the full text of any error message. On an error dialog, click **See details** and copy the text.
5. If you run your own server and the problem is on the server side, the lines of the Odoo log around the time of the error.

Do not send passwords, API keys or customer data. If we need access to look at something, we will agree how with you first.

## Report a bug

Send the details above with the subject **Bug: app name**. If you can, say whether the problem also happens in a fresh test database, which helps us tell an app problem from a setup problem.

## Ask for an improvement

We read every request. Write what you want to achieve and why, rather than how the screen should look. That helps us find a solution that also works for other users.

## Another Odoo version or a new app

The **Installation** page of each guide has a **Request this version** button for Odoo versions the app does not support yet. For an app we do not have, or an integration with another system, see [custom apps and integrations](https://novatorapps.com/services#request).

## Updates

New versions are published on the [Odoo Apps Store](https://apps.odoo.com/apps/browse?repo_maintainer_id=271577). The **Installation** page of each guide explains how to update, and the **Release notes** page lists what changed.

## Purchases and licences

Paid apps are sold through the Odoo Apps Store. Questions about a purchase, an invoice or downloading an app you bought go to Odoo through your Odoo account. For questions about what an app does before you buy, write to us.
